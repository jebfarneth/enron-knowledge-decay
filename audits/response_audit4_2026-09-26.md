# Response to audit 4 (2026-09-26)

Audit 4 ([report](audit4_codex_2026-09-26.md)) reviewed the audit-3 fixes, both
evaluations and the mention network. Each finding is listed with its
commits, effect on the regenerated data (full rerun on branch
`rebuild/audit4-fixes`: 237 unit tests and all 17 real-corpus checks pass,
and the stage manifest certifies the run) and what remains open.

| Finding | Status | Commits | Change and effect |
|---|---|---|---|
| M1 freshness gate cannot certify downstream results | fixed | `cba0eca` | Every stage ends by checksumming its declared outputs (parsed table, identities, sender attribution, person types, aliases, links, rank labels, edges, centrality, mention outputs, gold pairs and coverage, every result table, both figures) into `data/processed/manifest.json`, with the code and configuration hashes and a sequence number. The check requires every stage, built by the current code and configuration after the stages it reads, with exactly its declared outputs unchanged; a blank output list, a missing stage, a rebuild out of order or a missing manifest all fail. Only the two gold stages may be skipped; a skip deletes their processed files, result tables and coverage, and results built without gold pairs are rejected. Corpus checks skip only when `data/processed` is empty. Tests corrupt and delete every declared output. |
| M2 mention rows are not clean evidence of whom employees discuss | partly fixed | `52b34f9` | The main measures count only person-text messages (8,403 resolved rows from other senders drop out) and leave out names resolving to the sender (318,914 of 985,038 rows: signatures and contact lines), names after an office title (6,024) and before a company word or ending in one (1,775), and abbreviations ("Ste."). The earlier definition is kept as `*_unfiltered`. `mentioned_to` was declared the primary measure before this rerun, and the title-proxy table now always reports it against degree. **Effect:** on the main gold population it orders 91.3% (degree 89.6%; paired +1.7, −0.4 to +4.9), so the gain is no longer distinguishable from zero; unfiltered 92.2% (+2.7, +0.7 to +5.4); sender-and-recipient-excluded 92.3% (+2.7, +0.6 to +5.9). On the title proxy mention-network degree still leads degree (+6.8, +2.9 to +11.1). **Open:** residual quoted headers, rosters and signatures inside messages (Phase 3 redaction); a blinded message- and edge-level referent sample; employment of mentioned people. |
| M3 signature filter deletes substantive messages | fixed for the demonstrated cases | `7c00192`, `4bb9a91` | A signature block must name its sender (from the display name or address) in its first line and may follow only sign-off lines ("Cordially,"); anything else before it keeps the message. "Not I." and the Zufferli ranking table are unit and real-corpus regressions. Unsubscribe footers count as a newsletter only in link-heavy messages (three or more URLs). Signature-only messages: 1,366 to 1,161; structured records and newsletters: 8,639 to 6,763. **Open:** precision and recall of marginal internal-person exclusions on a labelled sample. |
| M4 wrong reply parents and relays | fixed for the demonstrated cases | `d865fa7`, `4d76833` | When the first quoted header names an author, only that author's messages qualify, even if an older ancestor is quoted deeper (Lavorato/Kitchen); a message quoting its own sender first is left unlinked (Cook/Kitchen); FW:/Fwd: subjects are forwards even when addressed back. Quoted authors are also read from bare Lotus name lines and one-line "Name <address> on date" headers (Kaminski/Hansen), and are matched on every key a sender goes by (person, raw address, display name), which recovered 1,190 links an address-only comparison lost. Each link records high, medium or low confidence. Links: 37,493 to 34,749 (26,889 replies, 7,860 forwards; 26,442 high confidence). On the first audit's labelled sample, 24 of 28 reply-kind links that keep their parent are direct replies (85.7%, was 77.4%). **Open:** a fresh, independently labelled precision and recall sample by confidence level. |
| M5 Phillips recipient repair fails | fixed | `957b28c` | Every piece of an address's local part is a possible surname, so `phillips.george@enron.com` blocks a second George Phillips; unresolved extra addresses are never added. A real-corpus check covers `forney-j/sent_items/96.`. **Open:** two genuinely distinct same-surname recipients listed only on other copies are still dropped (none found in the corpus). |
| M6 header syntax reintroduces quoted text | fixed | `50ccfc4` | Wrapped recipient lines in quoted headers may be short plain words (up to 40 characters, no sentence punctuation), matched one way per line so long bodies stay linear. `jones-t/notes_inbox/964.` is back to "I know nothing!" (unit and real-corpus checks); on 20,000 sampled bodies 5 outputs changed, all correct cuts. **Open:** quoted-span precision and recall on a fresh sample, including inline answers. |
| Minor 1 name compatibility | fixed | `52b34f9` | Hyphenated keys are indexed; an explicit middle initial rules out keys split under another initial; initials have their own keys and need capitals or periods, so "Ed" no longer matches E.D. |
| Minor 2 Cc agreement is endogenous | reported as such | `52b34f9`, README | Reported apart for one compatible person (84.7% of 8,111) and several (60.4% of 10,926), and described as a consistency check on the same graph, not an independent accuracy. **Open:** a withheld-edge or annotated check. |
| Minor 3 mention cache invalidation | fixed | `52b34f9` | Tags are cached under a digest of model name and version, spaCy version, active components, the character cap and the tagging code; a cache from before tagger identities is retagged. Tags now record where each name starts. |
| Minor 4 secondary dedupe chain | fixed | `957b28c`, tests | Every removed copy is chased to a live kept message, and the last copy's extra recipient reaches it; tested in four input orders. |
| Minor 5 surviving mutants | fixed | `52b34f9`, `d865fa7`, `cba0eca`, `0576ca3` | New tests: sender-plus-recipient distance, undirected distance, per-recipient resolution, Cc check strata, cache invalidation by components and cap, truncation, end-to-end quoted-author extraction through `threads.main` (fails when bare-name extraction is removed), gold intervals when two employees share a graph key (fails under key resampling), and a parse stamp holding the real Python and uv.lock values. |
| Minor 6 disclosure | fixed | README | Authored text is described as an estimate; the 5,000-character tagging cap, the method adaptation (spaCy for AceJet, abstaining ties) and the Cc check's limits are stated; the title-proxy comparison says "email-only measures"; the freshness claim describes the stage manifest. |
| Minor 7 stamp predates the last edit | fixed | this rerun | The rerun started after the last source edit; the corpus checks pass only because the manifest matches the current code, configuration and every output. |
